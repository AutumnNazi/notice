# 时辰筏

`时辰筏` 是一个运行在 Windows 10 / 11 上的桌面提醒工具。它支持单次提醒、固定间隔提醒、按星期提醒、按月日提醒和 Cron 表达式提醒，提醒通过 Windows 原生通知中心发送。

当前仓库里的代码已经不是“需求草案”，而是可运行、可打包、可直接使用的版本。

## 当前交付

- 程序名称：`时辰筏`
- 默认提醒标题：`时辰有讯`
- 源码入口：`main.py`
- 最终可执行文件：`dist/时辰筏.exe`
- 本地数据目录：`%USERPROFILE%/.notice_helper/`

## 直接使用

如果你只是要使用软件，而不是开发它，按下面方式操作即可：

1. 打开 `dist` 目录。
2. 双击 `时辰筏.exe` 启动程序。
3. 点击主界面右上角的“新建提醒”。
4. 填写标题、正文和提醒时间后保存。
5. 等待 Windows 通知中心在触发时间发送提醒。

## 已实现功能

### 提醒触发方式

- 单次定时：指定具体日期和时间，只触发一次。
- 循环间隔：按固定间隔重复提醒，例如每 30 分钟、每 2 小时。
- 按星期触发：选择周几，在固定时间提醒。
- 按月日触发：每年固定月日提醒，适合生日、纪念日。
- Cron 表达式：高级用户可以直接输入标准 5 段 Cron 表达式。

### 提醒内容

- 自定义标题
- 自定义正文
- 优先级：`普通` / `重要`
- 默认静默：当前版本不播放声音

### 任务管理

- 新建提醒
- 编辑提醒
- 删除提醒
- 启用 / 停用单条提醒
- 暂停全部提醒 / 恢复全部提醒
- 列表展示下次提醒时间
- 支持多条提醒并行运行

### 系统集成

- Windows 原生通知中心提醒
- 系统托盘图标
- 托盘菜单：打开主界面 / 暂停全部提醒 / 退出程序
- 开机启动
- 窗口关闭时可选择：
  - 直接关闭
  - 缩小到托盘
  - 每次询问
- 关闭弹窗支持“记住这次选择”

### 界面与设置

- 主界面支持中文字体切换
- 默认加载程序目录下的 `fonts/` 目录，并支持在设置里导入自定义字体目录
- 支持导入自定义字体目录
- 设置页集中管理：
  - 界面字体
  - 字体目录
  - 开机启动
  - 点击关闭时的行为

### 文案与语录

- 左上区域展示随机短句
- 内置 `171` 条本地语录
- 支持手动“换一句”
- 支持自动轮换

### 实时信息

- 主界面右上角展示实时天气，优先使用 Windows 设备定位，不可用时回退 IP 近似定位，并在数据来源上区分
- 展示当天的农历月日与生肖年
- 天气每 10 分钟自动刷新，拉取失败后每 1 分钟重试
- 断网或服务不可用时界面提示“天气暂不可用”，不影响提醒功能

## 日常使用说明

### 新建提醒

1. 点击“新建提醒”。
2. 在“提醒内容”里填写标题和正文。
3. 在“提醒时间”里选择触发方式。
4. 根据触发方式填写具体时间参数。
5. 点击“保存提醒”。

### 编辑提醒

- 在列表中选中一条提醒，点击“编辑选中项”。
- 或直接双击列表中的提醒行。

### 删除提醒

- 选中提醒后点击“删除选中项”。

### 启用或停用提醒

- 选中提醒后点击“停用/启用”。

### 暂停全部提醒

- 点击“暂停全部提醒”后，所有提醒暂停调度。
- 再次点击可恢复。

### 设置

- 点击主界面中的“设置”。
- 可以修改字体、导入字体目录、设置开机启动、设置关闭按钮行为。

## 关闭行为说明

点击窗口右上角关闭按钮时，程序会按设置决定行为：

- `每次询问`：每次点关闭都弹窗确认。
- `缩小到托盘`：窗口隐藏到托盘，程序继续后台运行。
- `直接关闭`：程序彻底退出。

如果你在关闭提示框里勾选“记住这次选择”，以后会直接执行该行为。

## 使用注意事项

- 提醒与语录完全本地运行；实时天气和农历需要联网与 Windows 定位/日历服务，不可用时会自动降级，不影响提醒功能。
- Windows 可能会对新生成的 `.exe` 弹出 SmartScreen 提示，需要手动允许运行。
- 如果修改了通知名称、图标或快捷方式后发现系统通知显示仍旧异常，通常重启一次程序即可刷新。
- 如果旧版本 `时辰筏.exe` 仍在运行，重新打包时可能无法直接覆盖，需要先退出旧进程。
- 字体目录导入的是本机可用字体，目录里需要包含 `.ttf` 或 `.otf` 文件。
- 过去时间的“单次提醒”不会继续调度，程序会自动视为过期。

## 当前已知特点

- 设置页和主界面已经过多轮调整，当前以“可用优先”为主。
- 提醒是静默通知，不会播放系统提示音。
- 语录为本地内置内容，不会联网拉取。
